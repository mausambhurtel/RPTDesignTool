RPTDesignTool - Quick Start

1. Open terminal in this folder.
2. (Recommended) Create and activate a python virtual environment.
3. Install dependencies first:
   pip install -r requirements.txt
4. Run the app:
   python main.py
5. Use the tabs step-by-step from Start to Export Design.

Notes:
-Keep .py files, image files, and CharacteristicFits1.xlsx in the same folder.
-The GUI of the app is created using ChatGPT. The GUI code maybe confusing.




Alternative: EXE file related to this code can be found in app/ directory.
